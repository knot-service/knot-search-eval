# 로컬 탐색 POST 전체 재생 · 2026-11-12 KST

v1.30 255건과 Workspace 1 0.2 초안 2,373건을 기존 로컬 Spring과 색인에 연결했다. 기대 문서 ID는 모두 로컬 코퍼스에 존재한다. 이력이 필요한 345건은 평가 전용 계정에 지정 이력을 저장하고, 이어지는 질문을 실제 탐색 POST로 보낸다. 나머지는 첫 질문 POST로 시작한다. 동시 요청은 2개다.

Qwen 게이트웨이가 모델 목록과 생성에 HTTP 502를 반환했다. 탐색 POST 사전 점검 4건은 Spring에서 HTTP 200으로 접수됐고 검색을 실행했지만, SSE는 모두 `ANSWER_GENERATION_FAILED`로 종료했다. Workspace 1은 W1-0001-01, W1-0002-01이고 v1.30은 S01-01, S01-02다. 기존 직접 연결도 시간 초과였다. 지정 Qwen의 모델 목록과 생성이 정상 응답한 뒤 로컬 재생기가 자동으로 재개했다. 기록된 문서 찾기 47건을 건너뛰고 생성 경로 2,581건을 처리 중이다.

문서 찾기 47건의 SSE 근거와 DB에 저장된 근거를 대조했다. 모델 생성 호출은 0회였다. 기대 문서 포함률 분모는 해당 문서가 지정된 문항만 포함한다. v1.30의 확인 질문 기대 S44-01~03과 결과 없음 기대 S50-03·S53-03·S66-03도 문서 링크를 반환했다.

첫 답변은 POST 발송부터 첫 비어 있지 않은 SSE `delta`까지, 완료는 POST 발송부터 SSE `completed`까지다. p50과 p95는 최근접 순위로 계산했다. 위 표는 문서 찾기만 집계한다. v1.30의 30개 보류 문항은 권한 변경·장애·재연결 등 별도 상황 설정이 필요하다. 현재 일반 POST에서 얻은 결과는 보류 시나리오 재현으로 집계하지 않는다.

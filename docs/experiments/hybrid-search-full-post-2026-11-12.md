# 로컬 탐색 POST 전체 재생 · 2026-11-12 KST

v1.30 255건과 Workspace 1 0.2 초안 2,373건을 기존 로컬 Spring과 색인에 연결했다. 기대 문서 ID는 모두 로컬 코퍼스에 존재한다. 이력이 필요한 345건은 평가 전용 계정에 지정 이력을 저장하고, 이어지는 질문을 실제 탐색 POST로 보낸다. 나머지는 첫 질문 POST로 시작한다. 동시 요청은 2개다.

Qwen 게이트웨이가 모델 목록과 생성에 HTTP 502를 반환했다. 탐색 POST 사전 점검 4건은 Spring에서 HTTP 200으로 접수됐고 검색을 실행했지만, SSE는 모두 `ANSWER_GENERATION_FAILED`로 종료했다. Workspace 1은 W1-0001-01, W1-0002-01이고 v1.30은 S01-01, S01-02다. 기존 직접 연결도 시간 초과였다. 지정 Qwen의 모델 목록과 생성이 정상 응답한 뒤 로컬 재생기가 자동으로 재개했다. 기록된 문서 찾기 47건을 건너뛰고 나머지 2,581건을 실행했다.

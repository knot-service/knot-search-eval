원본 실행 자료는 [`data/live-qwen-http-sse-2026-11-06.json`](../data/live-qwen-http-sse-2026-11-06.json)에 있다. 로컬 평가는 같은 artifact를 로컬 `knot_eval`에 가져오며, Vercel view에서는 커밋 artifact를 읽기 전용으로 표시한다. 이 dataset/run 3건은 Vercel DB에 중복 적재하지 않는다. 2026-11-06 11:57 KST에 인증된 Vercel API에서 artifact를 포함한 로컬과 동일한 118개 평가셋·2,203개 실행·9,859개 검수 기록을 확인했다. ## 해석

- 복합 질문은 두 요청을 모두 처리하지 못했고 결제 담당자 민지를 누락했다.
- 두 번째 후속 질문은 사용자가 명시한 결제 대상이 실제 검색으로 전달되기 전에 decoder에서 실패했다.
- 명시적 로그인 반대 사례는 같은 대화 상태에서 성공했다. 다만 한 번의 관측으로 안정성이나 A/B 우열을 결론내리지 않는다.
- 전체 Qwen 호출 수, SQL 검색 자체의 지연, SSE 클라이언트의 첫 delta 시각, DB 저장 지연은 수집되지 않았다. UI에서는 이를 추정하지 않는다.
- 사후 품질 판정은 Codex의 검토이며 사람 검수는 아직 없다.
- 테스트 인스턴스는 기존 schema를 읽기 전용으로 확인한 뒤 Flyway를 끄고 실행했다. v59 checksum mismatch를 수정한 것이 아니다.
